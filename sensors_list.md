
# Smart Agriculture — Sensors & Parts List

- Soil moisture sensor (capacitive) — e.g., DFROBOT SEN0193
- Soil temperature sensor — DS18B20
- Air temperature and humidity — DHT22 or BME280
- Light sensor (lux or PAR) — BH1750 or photodiode
- Soil electrical conductivity (EC) sensor
- pH sensor (optional) — analog probe
- NDVI-capable camera or multispectral camera (drone or fixed)
- Rain gauge — tipping bucket
- CO2 sensor (optional) — MG-811 / SenseAir
- Actuators: solenoid irrigation valves, relays, fertilizer dispenser
- Edge hardware: ESP32 for sensors, Raspberry Pi as gateway
