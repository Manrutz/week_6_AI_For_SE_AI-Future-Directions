📌 Project Overview

This project explores cutting-edge directions in Artificial Intelligence, including:

Edge AI using TensorFlow Lite

TinyML deployment on constrained devices (Raspberry Pi / Microcontrollers)

AI + IoT integration for smart agriculture

Explainability via SHAP

Data-based simulation using LightGBM

It is part of the AI Future Directions assignment under the theme:
